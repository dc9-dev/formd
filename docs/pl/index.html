Formularze dla stron statycznych, na Twoim serwerze

formd to mały program obok Twojej strony. Przyjmuje zgłoszenia, odsiewa boty, zapisuje każde zgłoszenie w bazie SQLite na Twoim serwerze i wysyła powiadomienia przez Twój SMTP albo Amazon SES. Bez SaaS-u i bez captchy.

Treść ocenia polski model

Boty odpadają na tanich filtrach. To, co przez nie przejdzie, może jeszcze ocenić model językowy: czy to spam, oszustwo albo treść obraźliwa, czego dotyczy i jak jest pilne. formd korzysta z polskich modeli basal, uruchamianych na Twoim sprzęcie. Ocena jest opcjonalna i włączasz ją osobno dla każdego formularza.

  • Polski model na Twoim sprzęciebasal-omni-1.0-ultra (31B) na GPU NVIDIA albo lżejszy basal-2.0-4.5B zbudowany na Bieliku, który ruszy też na Macu i na CPU. Treść formularzy nie opuszcza serwera, a zapytania nic nie kosztują.
  • Bez GPU: Jev przez OpenRouterTen sam zestaw pytań w zewnętrznym API, ok. 0,00002 USD za zgłoszenie. Adresy e-mail są zastępowane samą domeną.
  • Ty decydujesz, co z podejrzanymiWstrzymaj do zatwierdzenia w panelu, oznacz [SPAM?] w temacie albo odrzuć. Model działa dopiero po wszystkich tanich filtrach, więc boty z pokazu wyżej w ogóle do niego nie docierają.

Instalacja modelu i konfiguracja formd krok po kroku: README.

Postaw to u siebie

Potrzebujesz serwera z Linuksem, domeny i nginx albo Caddy. Wpisz swoją domenę, a wszystkie polecenia poniżej się do niej dopasują.

Gdzie leży strona

formd będzie pod https://twojastrona.pl/f/, obok strony.

formd stanie na subdomenie https://forms.twojastrona.pl/f/. Dodaj dla niej rekord DNS A wskazujący na ten serwer.

  1. Pobierz formd

    Jedna statycznie linkowana binarka dla Linuksa x86-64 albo ARM64. Sprawdź sumę kontrolną przed instalacją.

    Wolisz zbudować sam? Wystarczy Go 1.27.2 lub nowsze: go build -o formd ./cmd/formd w sklonowanym repozytorium.

    curl -LO https://github.com/dc9-dev/formd/releases/download/v0.3.0/formd-linux-amd64
curl -LO https://github.com/dc9-dev/formd/releases/download/v0.3.0/SHA256SUMS
sha256sum --check --ignore-missing SHA256SUMS

  2. Zainstaluj usługę

    Skrypt zakłada systemowego użytkownika formd, kopiuje binarkę do /usr/local/bin, tworzy /etc/formd/formd.env z uprawnieniami 0640 i instaluje utwardzoną jednostkę systemd.

    git clone --depth 1 --branch v0.3.0 https://github.com/dc9-dev/formd
cd formd
sudo sh deploy/install.sh ../formd-linux-amd64

  3. Ustaw pocztę

    W /etc/formd/formd.env wybierz sposób wysyłki. Zacznij od log, jeśli chcesz najpierw sprawdzić formularz bez wysyłania maili.

    MAILER=smtp
MAIL_FROM="Strona <no-reply@twojastrona.pl>"
SMTP_HOST=smtp.twojastrona.pl
SMTP_PORT=587
SMTP_USER=
SMTP_PASS=
SMTP_TLS=starttls
    MAILER=ses
MAIL_FROM="Strona <no-reply@twojastrona.pl>"
AWS_REGION=eu-central-1
# poświadczenia: rola IAM instancji albo
# AWS_ACCESS_KEY_ID i AWS_SECRET_ACCESS_KEY
    MAILER=log
# maile trafiają tylko do dziennika:
# journalctl -u formd -f

  4. Uruchom i załóż konto

    Konto do panelu wymaga hasła z co najmniej 12 znaków. Hasło jest zapisywane w argon2id.

    sudo systemctl enable --now formd
sudo -u formd formd -env /etc/formd/formd.env user add admin

# formd odpowiada tylko lokalnie
curl http://127.0.0.1:8025/healthz

  5. Wystaw /f/ przez HTTPS

    formd słucha tylko na 127.0.0.1, więc świat widzi go przez Twój serwer WWW. Przekazuj wyłącznie ścieżkę /f/, nigdy panelu.

    Caddy sam pobierze certyfikat przy pierwszym starcie.

    # sudo certbot --nginx -d twojastrona.pl
server {
    listen 443 ssl;
    server_name twojastrona.pl;
    ssl_certificate     /etc/letsencrypt/live/twojastrona.pl/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/twojastrona.pl/privkey.pem;
    root /var/www/twojastrona.pl;

    location /f/ {
        client_max_body_size 64k;
        proxy_pass http://127.0.0.1:8025;
        proxy_set_header Host            $host;
        proxy_set_header X-Real-IP       $remote_addr;
        proxy_set_header X-Forwarded-For $remote_addr;
    }

    location / { return 404; }
}
    twojastrona.pl {
    root * /var/www/twojastrona.pl
    handle /f/* {
        request_body {
            max_size 64KB
        }
        reverse_proxy 127.0.0.1:8025 {
            header_up X-Real-IP {remote_host}
        }
    }
    handle {
        file_server
        respond 404
    }
}

  6. Otwórz panel i dodaj formularz

    Panel działa na osobnym porcie i nie wychodzi do internetu. Otwierasz go tunelem SSH ze swojego komputera, potem wchodzisz na http://localhost:8026.

    W panelu utwórz formularz kontakt, dodaj origin https://twojastrona.pl, ustaw pola i adres, na który mają przychodzić powiadomienia. Potem go włącz.

    ssh -L 8026:127.0.0.1:8026 twojastrona.pl

  7. Wstaw formularz na stronę

    Zwykły HTML i jeden skrypt, który pobiera token i liczy proof-of-work. Gotowy kod dla każdego formularza jest też w panelu, w zakładce „Kod HTML”.

    Jeśli strona ma nagłówek CSP, dopisz forms.twojastrona.pl do script-src, connect-src i form-action.

    <form action="/f/kontakt" method="post" data-formd="ajax">
  <input name="name" required>
  <input type="email" name="email" required>
  <textarea name="message" required></textarea>
  <div style="position:absolute;left:-10000px" aria-hidden="true">
    <input name="website" tabindex="-1" autocomplete="off">
  </div>
  <button>Wyślij</button>
  <p data-formd-status role="status"></p>
</form>
<script src="/f/formd.js" defer></script>

  8. Sprawdź z zewnątrz

    Skrypt i token powinny odpowiadać przez HTTPS. Potem wyślij formularz ze strony i zobacz zgłoszenie w panelu.

    curl -I https://twojastrona.pl/f/formd.js
# HTTP/2 200

curl https://twojastrona.pl/f/kontakt/challenge
# {"bits":16,"min_seconds":3,"token":"…"}

Kopie zapasowe, aktualizacje, fail2ban i ocena treści: README na GitHubie.

Pytania

Jak dodać formularz kontaktowy do strony statycznej bez SaaS-u?

Zainstaluj formd na serwerze z Linuksem, przekaż ścieżkę /f/ przez nginx albo Caddy po HTTPS, utwórz formularz w panelu i wklej na stronę zwykły formularz HTML z jednym skryptem. Instrukcja wyżej prowadzi przez każdy krok dla Twojej domeny.

Czy formd to darmowa alternatywa dla Formspree, Netlify Forms albo Basin?

Tak. formd jest otwartym oprogramowaniem na licencji AGPL-3.0 i działa na Twoim serwerze, więc nie ma abonamentu ani limitu zgłoszeń poza tymi, które sam ustawisz. Zgłoszenia zostają w bazie SQLite na Twoim serwerze, a nie u zewnętrznej firmy. W zamian potrzebujesz serwera, na którym go uruchomisz.

Czy działa z GitHub Pages, Netlify, Cloudflare Pages albo S3?

Tak. Strona zostaje tam, gdzie jest, a formd działa na subdomenie, np. forms.twojastrona.pl, na serwerze, który kontrolujesz. Formularz wysyła dane właśnie tam. Jeśli strona już stoi na Twoim serwerze, formd działa obok niej pod /f/.

Jak formd zatrzymuje spam bez captchy?

Każdy formularz dostaje podpisany, jednorazowy token, a przeglądarka przed wysłaniem rozwiązuje małe zadanie proof-of-work SHA-256. Serwer sprawdza potem źródło, limity dla IP, minimalny czas wypełnienia, ukryte pole-pułapkę i powtórzoną treść. Bot dostaje informację o sukcesie, ale nic nie jest zapisywane ani wysyłane.

Czy może sprawdzać treść wiadomości przez AI?

Opcjonalnie. formd może zapytać polskie modele basal działające na Twoim sprzęcie albo Jev przez OpenRouter, czy wiadomość to spam, oszustwo lub treść obraźliwa. Podejrzane zgłoszenia możesz wstrzymać do zatwierdzenia, oznaczyć albo odrzucić.

Gdzie są zapisywane zgłoszenia i jak je wyciągnąć?

W bazie SQLite na Twoim serwerze. Przeglądasz je w panelu, eksportujesz do CSV albo poleceniem formd export. Każde zgłoszenie dostajesz też mailem przez swój SMTP albo Amazon SES.

Czego potrzebuję, żeby go uruchomić?

Serwera z Linuksem (x86-64 albo ARM64), domeny, nginx albo Caddy do HTTPS oraz konta SMTP albo Amazon SES. formd to jedna binarka bez innych zależności.
